# Java Placement Coding Preparation Course

Welcome to the **Java Placement Coding Preparation Course**! This course is designed specifically for **C++ programmers** who want to learn Java quickly for placement coding rounds and technical interviews at mass-hiring companies like Accenture, Cognizant, Capgemini, L&T, etc.

Since you already know C++ and Data Structures & Algorithms (DSA), this course does **not** teach programming from scratch. Instead, it serves as a **C++ → Java bridge**, focusing entirely on syntax differences, standard coding practices, memory models, and standard libraries (Java Collection Framework vs C++ STL).

## 🎯 Target Audience & Placement Focus

- **Target Companies:** Accenture, Cognizant, Capgemini, L&T Infotech, TCS, Wipro, Infosys, and similar mass recruiters.
- **Your Prerequisite:** Solid knowledge of C++ and basic DSA (arrays, strings, recursion, hashing, sorting, trees, etc.).
- **What is NOT covered (Out of Scope):** Spring Boot, Hibernate, JDBC, GUI (Swing/AWT/JavaFX), Advanced Multi-threading, File handling, Maven/Gradle, JSP/Servlets.

## 🚀 Recommended Study Methodology

1. **Chapter-by-Chapter Read:** Skip items that feel redundant, but do not skip the **"Important Java differences"** and **"Common mistakes"** sections.
2. **Interactive Coding:** Write standard solutions on LeetCode/GeeksforGeeks/CodingNinjas in Java as you progress.
3. **Striver Mapping (Ch 14 & 15):** When solving Striver's SDE sheet, refer to these documents to convert your C++ logic to Java.
4. **Mock Preparation:** Read the 100 Interview Questions and solve the 50 Practice Problems before actual test/interview days.
